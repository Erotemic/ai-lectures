# Story-first orientation: all nine works in 20th-century literature

## Outcome

All nine existing novel analyses have complete, spoiler-containing story-orientation sequences immediately preceding them in `track.json` order. The three *To Kill a Mockingbird* episodes came from the previous Agent A delivery. This overlay adds story episodes for the eight remaining works. It does not change any of the analysis lectures or shared tests.

## Editorial direction

- Narrate what happens and who is involved in original, plain spoken prose; do not assume prior reading.
- Include the ending and the causal connections that explain how the characters got there.
- Use multiple segments where a novel needs generations, changes of setting, or different major stages of action.
- Do not interrupt storytelling with interpretive thesis statements, thematic essays, or genre surveys.
- Avoid invented quotations, reconstructed dialogues, and pretending to reproduce a copyrighted novel.
- Keep sources in nonspoken companions and metadata. The novels themselves remain the main reference.
- Descriptive word counts are measured from narration only. There are no length minimums or maximums.
- A source record documents where to verify the narrative; it is not evidence that every plot detail has been independently checked against a physical copy of the primary novel.

## Follow-up quality work

1. Listen to at least the start and end of each consecutive TTS episode and adjust pronunciation, pauses, and transitions if the synthesis is unclear.
2. For the Buendía family, consider a separate optional audio cast orientation if listener feedback indicates that names are difficult to follow; it would fit in the existing numerical gaps only if genuinely necessary.
3. Review each plot's proper names against an authoritative edition during later editorial QA; avoid treating third-party synopses as a substitute for the novel.
4. Do not amend shared tests or infrastructure from Agent A. The current tests already permit sub-thousand IDs.
