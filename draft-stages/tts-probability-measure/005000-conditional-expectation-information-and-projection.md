# Conditional Expectation: Information, Averages, and Projection

Imagine an engineer trying to predict tomorrow's electricity demand. The engineer knows the hour, the day of the week, and the weather forecast, but not the exact behavior of every household. There is a true future demand, and there is the information available now. What number should the engineer announce? The answer is not simply the overall average demand. It is an average that changes with the information the engineer actually possesses.

Conditional expectation formalizes this idea. It turns the vague phrase “what I expect, given what I know” into a precise mathematical object. Sometimes that object is a number. More often it is itself a random variable: a prediction that takes different values in different information states. It is central to statistics, probability, martingales, Bayesian inference, and estimation in function spaces.

A useful way to understand it is to start with a finite example, then ask what survives when the information is continuous or partial. We will see that conditional expectation preserves averages on every event visible to the observer, that it is an orthogonal projection when squared error is finite, and that conditioning is not the same as selecting a single outcome from a probability-zero event.

## The prediction depends on what can be distinguished

Suppose a factory runs one of two production modes, normal or intensive. Each is equally likely on a randomly selected day. In normal mode demand is ten units with probability three quarters and fourteen units with probability one quarter. In intensive mode demand is fourteen units with probability one quarter and eighteen units with probability three quarters.

Before the mode is known, expected demand is fourteen units. To see why, normal mode has average eleven, because three quarters of ten and one quarter of fourteen average to eleven. Intensive mode has average seventeen, by the same calculation. Half the days are in each mode, so their averages combine to fourteen.

Now imagine that a dashboard reveals the mode at the start of the day. If the dashboard says normal, a reasonable squared-error prediction is eleven. If it says intensive, the prediction is seventeen. The forecast is not one number chosen before observation. It is a rule: announce eleven in one information state and seventeen in the other.

This rule is a random variable because the displayed mode is random before we see it. Conditional expectation describes the rule, not just the value after a particular display appears. Calling it an average conditioned on mode is correct, but the phrase can hide this important distinction between a constant and a measurable function of information.

Suppose the dashboard breaks and displays the same symbol in both modes. We can no longer distinguish them. The best prediction returns to fourteen. The underlying demand process has not changed. Only the information available for predicting it has changed.

There is a valuable asymmetry here. More information may change the prediction; it does not force the prediction to become numerically larger. It may go up for some observations and down for others. Across all days, the average of the informed predictions remains fourteen.

## Why an information set is a sigma algebra

In a finite world, information partitions outcomes into groups the observer cannot distinguish. Knowing the factory mode divides all outcomes into normal days and intensive days. An event is observable if it can be described by a union of whole groups. The dashboard can tell whether the mode is intensive, but not whether the exact demand will be eighteen if that remains hidden.

The family of events that can be decided from the available information forms a sigma algebra. The smallest such family contains only the empty event and the entire sample space: it represents knowing nothing beyond the model. The full sigma algebra, by contrast, represents knowing every modeled event. Between these extremes are the sigma algebras generated by a mode display, a thermometer reading, or a collection of earlier measurements.

Denote the available information by script G and the random quantity to be predicted by X. We want a random variable Y determined by that information. That means Y must be measurable with respect to script G. If two outcomes are indistinguishable to the observer, Y cannot assign them different reported values.

There is a second requirement. On every event A that the observer can recognize, Y must have the same average total as X. In mathematical language, the expectation of Y times the indicator of A equals the expectation of X times that indicator. This is the defining balance property of conditional expectation, under the assumption that X is integrable.

In our factory example, take A to be the event that the dashboard says normal. The contribution from X on that event is one half times eleven, or five and a half units across all days. The forecast Y equals eleven on that same event, so its contribution is also five and a half. The intensive event works analogously. Because every observable event is a union of these groups, the equality holds on every event the dashboard can identify.

This balance condition is more informative than the single equation saying the unconditional averages agree. Many wildly inaccurate forecasts average to fourteen overall. Requiring the equality separately on each observable event rules those forecasts out.

## The finite construction and a first proof

For a finite partition into events with positive probability, construction is simple. On each partition cell, take the mean of X restricted to that cell. Assign that mean as the value of Y on the whole cell. The result can be computed from ordinary conditional probabilities and finite sums.

Why does this construction satisfy the defining property? Let an observable event consist of several cells. Within each cell, the forecast's constant value multiplied by the cell's probability equals the expected contribution of X from that cell. Summing over the cells gives the equality for their union. Thus the balance condition holds for every event the observer can distinguish.

Why is this prediction unique? Suppose two information-measurable forecasts satisfy the balance condition. In a finite partition, their average contributions must agree on each positive-probability cell. Since each forecast is constant on that cell, their values must agree there. A difference can remain only on cells of probability zero, where the balance equation has no power to identify a value.

The same qualification survives in general probability spaces. Conditional expectation is unique almost surely, not necessarily at every logically possible outcome. Two versions that differ only on a null set describe the same conditional expectation. This is not a defect of the definition; ordinary integration ignores changes on sets of measure zero as well.

For general sigma algebras, the existence theorem uses measure theory rather than a finite table. An integrable X defines a signed measure on observable events by assigning to A the integral of X over A. This signed measure is absolutely continuous with respect to probability restricted to the observer's sigma algebra. The Radon–Nikodym theorem provides an integrable observable density Y, which has exactly the balance property we require. Positive and negative parts are handled with their usual integrability assumptions.

It is worth distinguishing the proof of existence from a recipe for numerical prediction. A theorem guarantees that an appropriate random variable exists under the stated assumptions. Computing it in a complicated statistical model may still be difficult or impossible with available data. Those are separate questions.

## When the information grows, error can only improve

Return briefly to the factory's two-mode dashboard. The uninformed mean fourteen misses the normal-mode expectation by three and the intensive-mode expectation by three, though in opposite directions. Over the distribution of modes, this adds nine units of expected squared error beyond the unavoidable variability remaining after mode is known. Revealing mode therefore has a measurable value under squared loss. In another factory, if both modes happened to have the same conditional mean, the additional dashboard would not reduce mean squared prediction error at all, even if it disclosed other useful information about the shape of demand. Information has value relative to a target and a loss function, not by itself.

The projection identity explains this formally. We are not claiming every richer display leads to a strictly better forecast. We claim the set of allowable predictions becomes larger. An optimizer over a larger set cannot do worse, because the old prediction is still available. Strict improvement requires that the new information change the conditional mean on a set of positive probability. This interpretation connects information to decision-making without claiming that a perfect prediction system exists.

## Averages inside averages

The most immediate consequence of the defining equation comes from taking A to be the entire sample space. The conditional forecast and the original quantity have the same overall expectation. The factory engineer's informed prediction has mean fourteen, exactly like actual demand. One can change forecasts with new information without changing their unconditional average.

Now suppose there are two dashboards. One reveals only whether it is a workday. Another reveals both the day type and the factory mode. The second gives at least as much information as the first. If we compute expected demand with the richer display and then average that forecast using only the poorer display, we obtain the same forecast that we would get by conditioning directly on the poorer display.

This is the tower property. It reflects a practical principle: when an intermediate calculation uses information we will later discard, averaging away that extra detail gives the appropriate coarser forecast. It is not permission to drop conditioning variables indiscriminately; the information sigma algebras must be nested for this simple form of the tower identity.

We can prove the tower property without reciting a long formula. Let Z be the conditional expectation of X using the richer information. Let W be the conditional expectation of Z using the poorer information. W is measurable using the poorer information. For every event visible on the poorer dashboard, that event is also visible on the richer one. By the balance property for the richer forecast, X and Z have the same integral there. By the balance property for W, Z and W also have the same integral there. Thus X and W agree on the integrals of every poorer observable event. That is exactly the defining property of conditioning X directly on the poorer information. Uniqueness gives the result.

Notice what made the proof possible. We did not need to inspect the details of X or any probability density. We used only the defining test against every observable event and the inclusion of one information collection in another.

## Conditional expectation as a squared-error projection

The factory engineer might object that we have named an average but not justified the word best. To justify it we must specify a loss function. Let the loss be squared prediction error: the square of the difference between the true demand X and the predicted value Z. Suppose X has finite second moment, and allow Z to be any square-integrable random variable determined by the available information.

The conditional expectation Y is then the unique best prediction up to almost-sure equality. More exactly, every such Z has expected squared error at least that of Y. This is the Hilbert-space projection interpretation of conditional expectation.

To see why, compare X with Z in two steps. First go from X to Y, the conditional mean. Then go from Y to Z, the alternative prediction. The squared length of the whole error is the square of the first error plus the square of the second difference plus a cross term. The key assertion is that the cross term has expectation zero.

Why is it zero? The difference Y minus Z is determined by the available information. The residual X minus Y has zero conditional expectation on that information, by linearity and the fact that Y is already observable. Multiplying the residual by an observable square-integrable quantity and taking expectations gives zero. This last step follows first for bounded observable quantities from the balance property, and then by truncation and square-integrable approximation.

The expected squared error of Z therefore equals the expected squared error of Y plus the expected square of the difference between Y and Z. The extra term is nonnegative. It vanishes only when Z equals Y almost surely. That proves optimality.

This is more than a convenient statistical fact. Consider all square-integrable random variables as a space with an inner product given by expected products. The random variables measurable with respect to the available information form a closed subspace. Conditional expectation is the orthogonal projection of X onto that subspace, and the residual is orthogonal to every admissible predictor.

The analogy is geometric rather than merely poetic. In ordinary Euclidean space, projecting a vector onto a line minimizes squared distance to that line. Here the vector is a random variable, the line becomes a possibly infinite-dimensional space of observable predictions, and distance is measured by expected squared error.

The caveat matters. Conditional expectation minimizes squared error, not every conceivable loss. For absolute-error loss, a conditional median rather than the conditional mean is generally optimal. For asymmetric penalties, a conditional quantile may be appropriate. A mathematical claim that a forecast is best requires naming the criterion.

## What if the observation is a continuous number?

Suppose the dashboard reports a continuous temperature. A specific reading, such as exactly twenty degrees in a continuous idealization, may have probability zero. The elementary expression for conditional probability of A given B, as a quotient with probability of B in the denominator, no longer applies when B is the exact-temperature event.

Conditional expectation does not need that quotient. It conditions on the sigma algebra generated by the temperature random variable. The resulting forecast is a measurable function of temperature, at least almost surely under the standard real-valued setting. We can write it as a function g evaluated at the observed temperature. The function g is determined only up to values on temperature sets having zero probability.

When a joint density exists and the marginal density of the observed temperature is positive, we can compute the familiar formula: integrate the hidden variable weighted by its conditional density. But the density formula is a special case, not the definition. It may fail as a calculation when no density exists, while conditional expectation remains well defined.

Here is an illustrative example. Let temperature T be uniform on the interval from zero to one, and suppose demand X is twice T plus a noise term whose conditional expectation given T is zero. Then the conditional mean of demand given T is twice T. The overall expectation of the forecast is one, just like the expectation of demand if the noise is integrable and has mean zero.

At an exact temperature value that the model assigns probability zero, two mathematical versions of the conditional-mean function might disagree and still satisfy every balance equation. In applied work a chosen regular conditional distribution can provide sensible values, but one should not confuse that chosen version with information logically fixed by measure-zero conditioning alone.

## Conditioning and independence

Suppose a factory's random maintenance shock is independent of every observable dashboard reading, and its mean is zero. The best squared-error prediction of the shock using the dashboard is zero. Knowledge about temperature and operating mode cannot predict an independent shock. In conditional-expectation notation, the conditional mean of an integrable variable independent of the information is its ordinary mean.

The proof is again a balance proof. For any observable event A, independence lets us factor the expected product of the shock and the indicator of A into mean shock times probability of A. Thus the constant mean satisfies the defining condition, and uniqueness identifies the conditional expectation.

Do not invert the claim carelessly. A random variable can have conditional mean zero given some information without being independent of it. For example, let T be an observed number and let a fair independent sign determine whether a hidden variable equals plus T or minus T. Its conditional mean given T is zero, yet its magnitude equals T and so depends on the observation. Conditional mean independence is weaker than full distributional independence.

This distinction is consequential in stochastic modeling. A sequence of prediction errors may have conditional mean zero while its conditional variance changes over time. Such errors can be martingale differences without being independent or identically distributed. Their average behavior and their uncertainty require separate analysis.

## A warning about estimators and available information

Conditional expectation describes what is mathematically optimal under a specified joint probability model. It does not magically reveal the true distribution. If the data-generating process is misspecified, or if an important variable was omitted, a computed conditional mean may predict poorly on real observations. The theorem certifies a relationship within a model, not the model's empirical validity.

There is also a question of what information is genuinely available when the prediction is made. A forecast trained using tomorrow's outcome as an input is not a forecast of tomorrow, however good its average squared error appears in a retrospective evaluation. Defining the information sigma algebra forces us to specify which measurements are accessible at prediction time.

The difference is especially important for machine learning. A system may estimate conditional expectations from samples, but the estimated function is itself uncertain and depends on a training procedure. The mathematical conditional expectation under the true joint law is the target. Finite data, feature selection, distribution shift, and estimation error determine how close an implemented predictor comes to that target.

Return to our factory. The overall mean fourteen is a valid prediction with no dashboard. With mode information the conditional mean becomes eleven or seventeen. That change preserves unconditional averages, satisfies a balance equation on each observable event, and strictly reduces expected squared error unless the mode was irrelevant. The same object is an average over compatible outcomes, a measurable function of information, and an orthogonal projection in a space of random variables.

That triple interpretation is the enduring insight. Conditioning is not just dividing two event probabilities. It is the mathematical operation of replacing an uncertain quantity with the best squared-error summary that the available information permits, while preserving its average on every event the observer could recognize.

## Mathematical companion (display only)

Let \((\Omega,\mathcal F,P)\) be a probability space, \(\mathcal G\subseteq\mathcal F\) a sub-sigma-algebra and \(X\in L^1(P)\). A conditional expectation \(Y=E[X\mid\mathcal G]\) satisfies

1. \(Y\) is \(\mathcal G\)-measurable and integrable;
2. \(E[Y\mathbf 1_A]=E[X\mathbf1_A]\) for every \(A\in\mathcal G\).

The Radon–Nikodym theorem establishes existence by taking the signed measure \(\nu(A)=\int_A X\,dP\) on \(\mathcal G\). It is unique \(P\)-almost surely.

For a finite partition \(\mathcal G=\sigma(A_1,\ldots,A_m)\) with each \(P(A_j)>0\),
\[
E[X\mid\mathcal G]=\sum_{j=1}^{m}\frac{E[X\mathbf1_{A_j}]}{P(A_j)}\mathbf1_{A_j}.
\]
The factory example: \(P(M=N)=P(M=I)=1/2\), \(E[X\mid M=N]=11\), \(E[X\mid M=I]=17\), and \(E[X]=14\).

**Tower property.** For \(\mathcal H\subseteq\mathcal G\subseteq\mathcal F\) and \(X\in L^1\),
\[
E[E[X\mid\mathcal G]\mid\mathcal H]=E[X\mid\mathcal H] \quad\text{a.s.}
\]

**Projection identity.** If \(X\in L^2\), \(Y=E[X\mid\mathcal G]\) and \(Z\in L^2(\mathcal G)\), then
\[
E[(X-Z)^2]=E[(X-Y)^2]+E[(Y-Z)^2].
\]
Use \(E[(X-Y)(Y-Z)]=0\), first for bounded \(\mathcal G\)-measurable test functions and then extend to \(L^2\) by approximation.

**Conditioning on a continuous variable.** On standard Borel spaces a regular conditional distribution exists; \(E[X\mid\sigma(T)]\) is represented by \(g(T)\) almost surely. A density formula, when defined, chooses a version of \(g\); it is not a definition of every conditional expectation.

**Loss comparison.** A conditional mean minimizes squared loss; a conditional median minimizes absolute loss (with possibly nonunique minimizers).

### Exercises with answers

1. **Coarsening.** If an event is invisible to \(\mathcal G\), must its indicator be \(\mathcal G\)-measurable? **Answer:** no. Only events in \(\mathcal G\) have observable indicators.
2. **Factory.** Calculate \(E[E[X\mid M]]\). **Answer:** \(\tfrac12\cdot11+\tfrac12\cdot17=14\).
3. **Projection.** What extra squared error results from always reporting 14? **Answer:** \(E[(E[X\mid M]-14)^2]=\tfrac12(11-14)^2+\tfrac12(17-14)^2=9\).
4. **Information.** If \(\mathcal H\subseteq\mathcal G\), can the minimum squared prediction error increase when \(\mathcal H\) is replaced by \(\mathcal G\)? **Answer:** no; richer information allows every older predictor and perhaps more.
5. **Counterexample.** Let \(T\) be nonconstant and \(S\) an independent fair sign. Is \(X=ST\) independent of \(T\) when \(E[X\mid T]=0\)? **Answer:** generally not, since \(|X|=|T|\).
