# The Yoneda Lemma: Knowing an Object by All Its Relationships

How well can you understand an object by asking every possible question about how it relates to other objects? A building can be described by its materials, or by all the ways one can enter it and leave it. A number can be described by its digits, or by the arithmetic relationships it participates in. These descriptions are not automatically equivalent, but in category theory there is an exact theorem saying that a certain comprehensive collection of relationships determines an object up to isomorphism.

The theorem is called the Yoneda lemma. It has a reputation for being difficult because its statement involves functors whose values are sets of arrows, and natural transformations between those functors. We will construct every part from a simple idea. Fix an object A. For every object X, look at all arrows from A to X. If we know how this set of arrows changes when X changes, we have a systematic record of how A can map into the rest of the category.

This record is called a representable functor. The remarkable claim is that, to specify a natural way of turning every arrow out of A into an element of another set-valued functor, we only need to specify one element of that other functor at A. The rest of the transformation is forced by compatibility with composition.

There is a lot to unpack in that statement. We will first see it in Set, where an arrow can be evaluated at a chosen element. Then we will prove the general theorem using the identity arrow of A. Finally we will explore why the result implies that an object can be recognized from its relationships to all other objects.

## An element is a map from a singleton

Let A be a set. A function from a one-element set into A is completely determined by the image of that one element. Thus an element a of A can be regarded as a map from a singleton into A. These are two descriptions of the same choice.

For example, if A is the set of primary colors red, blue, yellow, a function from a singleton into A has exactly three possibilities. Send the unique input to red, to blue, or to yellow. The set of these maps is naturally in bijection with A.

Why do we emphasize naturally? If f is a function from A to B, we can send an element a to f of a. Or we can start with the singleton map that picks a and then compose it with f. The resulting map from the singleton picks f of a. The two routes agree for every function f.

This elementary observation is a seed of Yoneda reasoning. An object can be probed by maps from a test object. A singleton probes the individual elements of sets. Other test objects reveal different information. A two-element set probes ordered pairs of elements. A free group on one generator probes choices of group elements through homomorphisms.

But for the Yoneda lemma we will first fix a source object A and examine maps from A into every target. The distinction between maps out of A and maps into A is essential; the two perspectives correspond to covariant and contravariant representable functors.

## The hom functor

Fix an object A in a locally small category C. Locally small means that for any two objects, the arrows between them form a set. Define H-sub-A of X to be the set of arrows from A to X. If f goes from X to Y, it takes an arrow h from A to X and produces the composite f after h, an arrow from A to Y.

Thus H-sub-A is a functor from C into Set. On objects it records all arrows out of A. On arrows it records the act of postcomposing with the given arrow. Identity maps leave h unchanged, and postcomposition respects composition by associativity.

We call this the covariant hom functor represented by A. The notation often used is Hom of A comma dash, where the dash marks the variable target. There is also a contravariant hom functor Hom of dash comma A, based on arrows into A and precomposition. We will derive the covariant version first.

Suppose A is a one-element set. Then Hom of A into X is naturally the same as X, because a function from a singleton selects an element of X. In that case the representable functor H-sub-A is naturally isomorphic to the identity functor on Set.

Suppose A instead contains two distinct elements. Then Hom of A into X is naturally the same as the set X times X. A function out of A chooses an output for each of its two inputs, producing an ordered pair. So the functor represented by a two-element set is the 'ordered pair of elements' functor.

For a finite set A with n elements, Hom of A into X behaves like the collection of n-tuples of elements of X, once we choose an enumeration of the inputs. The functorial structure is still well-defined without any enumeration: a map from X to Y acts by applying it to the outputs of each function from A.

## Evaluate a transformation at an identity

Now take an arbitrary functor F from C into Set. Suppose alpha is a natural transformation from H-sub-A to F. For each object X, alpha at X is a function that takes an arrow h from A to X and produces an element of F of X.

At the particular object A, the functor H-sub-A of A contains the identity arrow on A. We can apply alpha at A to this identity arrow. The result is an element of F of A. Call this element a.

That construction gives us a map from natural transformations to elements of F of A. Here is the question: can two different natural transformations produce the same element a when evaluated at the identity? And, conversely, does every element a of F of A arise from such a transformation?

Naturality answers both questions. Let h be any arrow from A to X. Regard h as a morphism in the base category C. Draw the naturality square for h. It compares the hom functor at A with the hom functor at X, and F at A with F at X.

Start at the identity arrow on A. If we apply the hom functor to h, we obtain h itself, because h composed with the identity is h. Then applying alpha at X gives alpha at X of h. On the other route, first apply alpha at A to the identity, obtaining a. Then apply F of h to a. Naturality forces these results to agree.

So alpha at X of h must equal F of h applied to a. This formula determines the entire natural transformation from the single element a. No choices remain. A natural transformation is determined by what it does to the identity arrow.

This is the key proof step. We did not assume that the category has elements of its objects. We used only identity arrows, composition, functoriality, and naturality. The element a lies in F of A, which is a set because F is set-valued.

## Build the inverse correspondence

To prove a bijection, we must also go backward. Start with any element a of F of A. Define, for each object X, a function alpha at X that sends an arrow h from A to X to F of h applied to a.

We need to verify naturality. Suppose f goes from X to Y. Start with h from A to X. Following alpha at X and then F of f gives F of f applied to F of h applied to a. Functoriality says this equals F of the composite f after h applied to a.

On the other route, first postcompose h with f to obtain f after h, then apply alpha at Y. By our definition, that also gives F of the composite applied to a. The naturality square commutes for every f.

Now apply the new natural transformation to the identity arrow at A. We get F of the identity applied to a, which is just a. Conversely, starting from a natural transformation alpha, extracting a, and then constructing the new transformation returns alpha because of the formula forced by naturality.

Therefore the set of natural transformations from the representable functor Hom of A comma dash to F is in bijection with the set F of A. That is the covariant Yoneda lemma. The correspondence is natural in the relevant variables, which makes the theorem much stronger than an accidentally matched number of elements.

The proof can fit in a few lines of symbols, yet the conceptual distance is substantial. We replaced a family of functions, one for every object X and compatible with every arrow, by a single element of a set. The identity arrow encodes exactly the universal test needed to recover the whole family.

## A concrete example with functions

Let C be Set. Fix a two-element set A, and let F be the identity functor. The Yoneda lemma says that natural transformations from the functor Hom of A comma dash, which behaves like X times X, into the identity functor correspond to elements of A.

A has two elements. We can describe the two natural transformations explicitly. Given an ordered pair of elements of X, return its first coordinate; or return its second coordinate. These are natural because applying a function to a pair and then taking a coordinate gives the same result as taking that coordinate and applying the function.

Could there be a third natural operation that chooses an element from every ordered pair, perhaps returning the first coordinate when the pair is equal and the second otherwise? In that particular example the rule simplifies to the second coordinate when unequal and either coordinate when equal, so it is just second projection. More elaborate rules that inspect values, such as choosing the alphabetically smaller element, are not defined on arbitrary sets with no supplied order and generally fail naturality under arbitrary renaming.

The Yoneda lemma proves that first and second projection are all the possibilities. Why? Such a natural transformation is determined by what it does to the identity map on the two-element set, which is itself the pair containing the two distinct elements in their original order. The output must be one of those two elements. Whichever it chooses determines the transformation everywhere.

This is a powerful example because the theorem rules out all conceivable extra operations, not just the ones we happened to imagine. Naturality imposes a rigidity that becomes visible through the representing object.

## The contravariant side

We can look at arrows into A rather than arrows out of A. For each X, take Hom of X comma A. A map f from X to Y induces precomposition, sending a map from Y to A back to a map from X to A. This gives a functor from the opposite category of C into Set, called a presheaf represented by A.

The contravariant Yoneda lemma says that natural transformations from Hom of dash comma A to a presheaf P correspond to elements of P of A. The proof has the same structure: evaluate a transformation on the identity arrow at A, then recover its value at any arrow by naturality.

The direction of arrows can make the statement look confusing. One reliable way to avoid errors is to write the domains of every map before manipulating the formula. In the covariant version, an arrow h from A to X pushes the chosen element a forward through F of h. In the contravariant version, an arrow from X to A pulls the chosen element at A back through the presheaf's action.

Both versions express the same structural principle. A natural transformation out of a representable functor is controlled by its value on the identity of the representing object.

## The Yoneda embedding

We can now compare objects by comparing their entire representable functors. Assign to each object A the presheaf Hom of dash comma A. A morphism f from A to B induces a natural transformation between the corresponding presheaves by postcomposition with f.

The Yoneda lemma says that every natural transformation between these representable presheaves comes uniquely from a morphism between A and B. In categorical language, the Yoneda embedding is fully faithful. It preserves exactly the arrow information, with no missing arrows and no accidental identification of different arrows.

One striking consequence is that if the representable presheaves associated with A and B are naturally isomorphic, then A and B are isomorphic in the original category. The natural isomorphism of all incoming-map sets determines an actual isomorphism of objects.

This does not mean that one arbitrary numerical invariant of an object determines it. Counting its arrows from one particular test object may tell us very little. Yoneda uses all test objects and the naturality constraints connecting their maps. The total pattern is what carries enough information.

In Set, the elements of A can be probed by singleton maps, and functions into A can be understood through their values. In more complicated categories, different test objects reveal richer structure. The theorem gives a precise expression of the idea that an object can be understood through all its relationships with other objects.

## Representable functors and universal properties

Universal properties can be expressed in terms of representable functors. That observation ties together a large portion of elementary category theory.

Take objects A and B in a category with their product P. For every test object X, a map from X into P corresponds uniquely to a pair of maps from X into A and from X into B. The correspondence is natural in X: if a map k goes from X-prime to X, precomposing a map X-to-P with k and then projecting its components produces the same pair as projecting first and precomposing each component with k.

Therefore the contravariant representable functor Hom of dash comma P is naturally isomorphic to the product of the functors Hom of dash comma A and Hom of dash comma B, where that product is taken pointwise in the category of set-valued presheaves.

We could treat this as an intimidating new notation. But it says exactly what the universal property said in words: to give a map into the product is to give a compatible pair of maps to its factors. The functor language packages the dependence on every test object X together with the compatibility under every change of X.

Suppose Q is another proposed product of A and B. It gives the same natural description of pairs of maps. Thus the representable presheaves of P and Q are naturally isomorphic. Yoneda then implies P and Q are isomorphic. The familiar uniqueness of products has emerged from the general principle that representing objects are determined by their mapping behavior.

A similar argument applies to coproducts, but the direction changes. Maps out of the coproduct into X correspond to pairs of maps out of the summands into X. This uses the covariant hom functors Hom of A comma dash and Hom of B comma dash. The direction is a helpful diagnostic: maps into a product, maps out of a coproduct.

We can view a terminal object T as representing the constant singleton-valued presheaf, because for every X there is exactly one arrow from X to T. If two terminal objects represent that same functor, Yoneda gives their isomorphism. The abstract theorem unifies the earlier uniqueness arguments, though their direct proofs are still valuable for learning.

## What does full faithfulness actually prove?

The Yoneda embedding takes an object A to its incoming-map presheaf, and takes an arrow f from A to B to postcomposition with f. Full faithfulness means that for every pair A,B, this assignment gives a bijection between arrows A-to-B and natural transformations from the presheaf of A to the presheaf of B.

We can verify the inverse explicitly. Start with a natural transformation alpha from Hom of dash comma A to Hom of dash comma B. At A, it sends the identity arrow of A to some arrow from A to B. Call that arrow f. Naturality forces alpha at every X to send an incoming map h from X to A to the composite f after h. Thus alpha is exactly the transformation induced by f.

Injectivity follows because two different arrows f and g would produce transformations taking the identity at A to two different arrows. Surjectivity follows because every natural transformation has the required form. The proof is only one application of the Yoneda mechanism, with the relevant functor itself representable.

Now suppose there is a natural isomorphism between the presheaves represented by A and B. Its forward and inverse transformations correspond to arrows f from A to B and g from B to A. Their composite transformations are identities, so by faithfulness the corresponding composites g after f and f after g are identity arrows. Hence A and B are isomorphic.

There is an important difference between this result and a claim that all objects are determined by a single label or numerical measurement. The presheaf contains the entire family of incoming-map sets, and naturality records how those maps change under precomposition. If we throw away the connecting information, the ability to recover the object may disappear.

## Why naturality rules out strange operations

The two-element-set example is small enough to show the power of the theorem without any advanced algebra. Fix a set A containing zero and one. For any set X, the set of functions from A to X is the set of ordered pairs of X-elements. A rule choosing an X-element from every ordered pair is a family of functions from X times X to X.

If the rule is natural, it commutes with every map f from X to Y. That includes arbitrary relabelings and functions that merge two previously distinct values. Evaluate the rule on the identity pair zero, one in A itself. It must return either zero or one. If it returns zero, naturality forces the rule on an arbitrary pair x,y to return x, because the function sending zero to x and one to y carries the identity pair to x,y. If it returns one, the rule must always return y.

So the only natural selectors are the two coordinate projections. We have proved the classification by one test at a universal pair, without individually examining each possible set X and every imaginable selection algorithm.

Consider the tempting rule 'return x if x equals y; otherwise return y.' It is actually just the second projection, because when x equals y both coordinates give the same answer. But the tempting rule 'return the smaller value' is not defined on sets without an order. If we add an ordering, we have changed the category and the class of allowed maps. Yoneda is precise about that dependence.

For three input positions, the theorem produces exactly three natural selectors. For the empty set of positions, there is no natural transformation from the constant singleton-valued functor Hom of empty comma dash into the identity functor on Set, because the Yoneda set of choices is empty. This recovers an intuitive fact: with no supplied input, there is no universal way to choose an element of every set, particularly the empty set.

The reasoning reveals why the identity arrow has such a privileged role. It is a generic input containing all the information needed to evaluate a natural rule on arbitrary arrows from the representing object. Every such arrow is obtained by postcomposing the identity. Naturality then propagates one chosen value to every target.

## What Yoneda does not say

It is sometimes tempting to describe the lemma as proof that objects have no internal properties and only relationships exist. The theorem is more careful. It assumes a category whose objects and arrows have already been defined. The particular choice of arrows determines what can be observed through relationships. If we change the category, we may change what the corresponding representable functor reveals.

For example, if we treat real vector spaces with all linear maps, their arrows preserve linear structure. If we forget down to underlying sets and allow all functions, we have changed the mathematical context. The resulting representable functors capture different kinds of structure. The Yoneda lemma applies in both categories, but it does not declare them equivalent.

The result also needs the correct naturality. Merely collecting the cardinalities of hom-sets is not enough. Two objects can have equally many maps from various sources while the way those maps compose still differs. Yoneda uses the actual hom-sets and their functorial action, not just their sizes.

Finally, the lemma is not a substitute for constructing universal objects. It tells us that a representing object is uniquely determined up to isomorphism when it exists, and it helps characterize maps from it. Existence can remain a difficult theorem. In geometry, algebra, and logic, considerable work often goes into showing that the desired functor is representable at all.

Those boundaries make the lemma more useful. Its conclusion is exact: natural transformations out of a representable functor correspond to elements at the representing object. From that one statement, we derive both practical classification results and the fully faithful embedding of a category into presheaves.

## Representation and mathematical practice

Yoneda's theorem is used widely because it converts apparently difficult questions about natural transformations into questions about individual elements, and because it allows objects to be characterized by their mapping behavior.

Suppose a functor F is represented by some object A. Then knowing the natural transformations from Hom of A comma dash to other functors becomes a manageable evaluation problem. If two objects represent naturally isomorphic functors, they are isomorphic in the appropriate categorical setting. This is a general route to uniqueness results for universal constructions.

A product, for instance, can be described by the fact that maps into the product correspond naturally to pairs of maps into its factors. In a suitable formulation, the product represents a functor that assigns to X the set of such pairs. Yoneda explains why a representing object, once it exists, is determined up to unique isomorphism compatible with the representation.

The theorem also clarifies an intellectual temptation. Category theory is sometimes advertised as a way to ignore objects altogether and look only at relationships. The Yoneda lemma gives a more exact statement: the complete, coherently organized pattern of relationships can recover objects up to isomorphism. It does not make the objects or their mathematical context disappear.

## A small theorem with large reach

We started with the idea of probing a set by functions from a singleton. Then we fixed an object A and considered the functor that assigns to each X its arrows from A. A natural transformation out of that functor looked like an enormous family of compatible rules. Evaluating it at the identity arrow of A produced one element, and naturality forced every other value.

The key equation is simple enough to remember in words: the transformation applied to an arrow h equals the functor applied to h acting on the chosen element at A. Once that relation is understood, the general proof is a straightforward check of composition and identity.

The extraordinary feature of Yoneda is its precision about what we may infer from relationships. It does not claim that a few observations will reveal everything. It says that all maps, organized functorially and compared naturally, preserve enough information to recover the categorical structure. That is why a theorem about maps into sets can illuminate universal constructions throughout mathematics.

## Mathematical companion (display only)

Let \(\mathcal C\) be locally small, \(A\in\mathcal C\), and \(F:\mathcal C\to\mathrm{Set}\). Write \(h^A=\mathcal C(A,-)\). Then \(\mathrm{Nat}(h^A,F)\cong F(A)\), naturally. For \(\alpha\) define \(a=\alpha_A(1_A)\). The inverse sends \(a\in F(A)\) to \(\alpha^a_X(h)=F(h)(a)\) for \(h:A\to X\). Naturality follows from \(F(f)F(h)=F(fh)\).

**Contravariant Yoneda:** For \(P:\mathcal C^{op}\to\mathrm{Set}\), \(\mathrm{Nat}(\mathcal C(-,A),P)\cong P(A)\).

**Yoneda embedding (for small \(\mathcal C\), or with a chosen universe):** \(y:\mathcal C\to[\mathcal C^{op},\mathrm{Set}]\), \(A\mapsto\mathcal C(-,A)\), sends \(f:A\to B\) to postcomposition. \(\mathrm{Nat}(yA,yB)\cong\mathcal C(A,B)\), so \(y\) is fully faithful.

**Two-element example:** For \(A=\{0,1\}\) in Set, \(\mathrm{Nat}(\mathrm{Set}(A,-),\operatorname{Id})\cong A\); the two transformations are coordinate projections \(X^2\to X\).

### Exercises and answers

1. **Exercise:** Describe natural transformations from the identity functor on Set to itself. **Answer:** Only the identity; the identity functor is represented by a singleton, and its Yoneda set has one element.
2. **Exercise:** What does a natural transformation from the functor \(X\mapsto X^3\) to \(X\mapsto X\) look like? **Answer:** One of the three coordinate projections, by Yoneda applied to a three-element representing set.
3. **Exercise:** Is a representable functor automatically set-valued? **Answer:** Yes when the category is locally small; otherwise the hom-collections may be proper classes.
