There are **16 short historical sketches** awaiting researched long-form expansion.

appear in the playable History track. The expanded biographies promoted from
this archive include Jordan, Rayleigh, Ritz, Weyl, Courant, Fischer, Riesz,
and von Neumann. Hilbert, Kato, Davis, and Kahan are also available as
long-form lectures.

The reader exposes only root-level lecture files listed in `../track.json`.
`manifest.json` records the remaining sketches, while `../metadata/sources.json`
holds the shared reading catalog.
