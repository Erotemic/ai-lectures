# Number Theory from First Principles

A self-contained proof-driven introduction to integer arithmetic: Euclid and primes, congruences and reconstruction, finite multiplicative arithmetic, Diophantine equations, continued fractions, Pell equations and the first ideas of quadratic reciprocity. Connects elementary proofs to abstract algebra, algorithms and arithmetic geometry.

The course starts from integer arithmetic and basic algebra. Every manuscript is standalone at its declared background level; the sequence is recommended because each proof supplies tools used later. The mathematics in companions is display-only and the lecture audio uses one delimited spoken region.

## How this fits the existing library

This pack complements rather than changes `draft-stages/tts-abstract-algebra/004000-*`, where congruences are introduced alongside rings and fields. It is also useful preparation for discrete algorithms, finite group theory, cryptography, algebraic number theory, and constructive proof techniques. The companion notes identify the assumptions on moduli and where a theorem is stated without proof.

## Sources and authorship

The primary course-level references are [MIT OpenCourseWare 18.781](https://ocw.mit.edu/courses/18-781-theory-of-numbers-spring-2012/pages/lecture-notes/) and [William Stein, *Elementary Number Theory*](https://www.wstein.org/ent/). Each lecture links directly to relevant Wikipedia background and has a structured sidecar with theorem anchors, reading-source IDs and an independent citation catalog in `metadata/sources.json`. Bibliographic pointers are not a claim that an entire source was reverified line by line.
