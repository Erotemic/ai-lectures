# Multivariable Calculus from First Principles

A calculation-first and proof-aware bridge from single-variable calculus and basic linear algebra to smooth manifolds, PDEs, optimization, and vector calculus. Develops limits in several variables, total differentiation, Jacobians, Hessians, constrained extrema, multiple integrals, change of variables, curves, surfaces and boundary theorems.
