# Linear Algebra from First Principles — new core mathematics track

**Created:** 2026-11-16, Mathematics Continuation 30. **Status:** 15 complete, standalone lecture narrations, each with exact mathematical companion, exercises with answers, reading sources and registered metadata. No duration target is imposed.

This is a **new mathematics collection**, rather than an insertion into the already advanced geometry track. It fills a genuine foundation gap found in the repository audit: there were Analysis, Differential Equations, Numerical Analysis and Topology/Geometry collections, but no standalone course developing vector spaces and matrices from the beginning.

## Editorial choices

The spoken regions are actual self-contained explanations, not one-paragraph outlines. Mathematical notation, derivations, exercises and exact hypotheses are repeated in non-spoken companions. Referenced educational sources are registered in metadata/sources.json. The order prioritizes concepts repeatedly assumed by other tracks rather than pushing immediately into a second advanced algebra sequence.
