# Linear Algebra from First Principles

A calculation-first and proof-driven course from linear equations, spans and bases through linear maps, determinants, eigenmodes, orthogonality, singular values, duals, multilinear forms and exact sequences. Supplies the missing algebraic foundations for advanced analysis, topology, geometry, differential equations, optimization and numerical methods.
