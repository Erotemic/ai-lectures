# Linear Algebra from First Principles — following foundations

**Completed in Continuation 30:** 001000–015000 inclusive (15 lectures).

High-priority follow-ups when another core-foundations pass is requested:

- Matrix rank factorization, LU and QR by calculation and floating-point pivoting, beyond the symbolic introductions in 001000 and 009000.
- Cayley–Hamilton, Jordan blocks, generalized eigenvectors, matrix exponentials and primary decomposition: bridge to ODEs and functional calculus.
- Spectral theorem in function spaces, compactness and unbounded-operator domains: link explicitly to the Analysis track rather than pretending finite-dimensional arguments generalize directly.
- Exterior powers, orientations and Jacobians beyond the first worked coordinate-change example.
- Matrices over finite fields; characteristic-sensitive caveats; quadratic-form classification and symplectic linear algebra.
- **Additional curriculum-wide core gap:** multivariable calculus from first principles, including directional derivatives, partial derivatives, chain rule, Jacobians, gradient, constrained extrema, and change-of-variables theorems. Existing analysis begins in one-variable calculus, and the topology track later introduces manifolds and forms; a dedicated bridge would be valuable.
- Proof methods and mathematical writing: quantifiers, induction, direct/contradiction, construction and counterexamples, separate from advanced type-theoretic lectures.

Decide follow-up scope by dependency audit, not a fixed number of minutes or words.
