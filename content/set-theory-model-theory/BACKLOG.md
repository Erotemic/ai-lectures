# Further Topics (Not Needed for the Foundation Sequence)

The eight-lecture foundation course stands on its own. Extensions are optional and should be added when there is a specific mathematical or formalization use:

- Ultraproducts, the Łoś theorem, and elementary equivalence beyond the introductory Tarski–Vaught argument.
- Types, saturation, elementary embeddings, and basic classification/stability questions.
- Forcing and independence proofs for the continuum hypothesis; a full technical course would need ordinals, models, and Boolean-valued or forcing constructions.
- Infinite combinatorics and descriptive set theory, including trees on Baire space and the Borel hierarchy.
- Formalization of first-order syntax, satisfaction, and completeness in a proof assistant, with explicit treatment of object logic versus metalogic.

Avoid duplicating the existing `logic-types` course on dependent type theory or `mathematical-proof` introductions. A formalization-focused continuation should choose an actual repository and named theorem statements before writing.
