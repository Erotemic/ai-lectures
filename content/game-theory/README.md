# Game Theory: Choices, Equilibria, and Designed Rules

Five complete, audio-first foundation lectures build game theory from finite payoff tables to rules that make truthful reporting rational. The emphasis is on solvable mathematical examples, proof certificates, and the hypotheses that separate one equilibrium concept from another. No economics training is assumed.

## Listening order

- `game-theory:001000` - **When Randomness Becomes a Strategy**: zero-sum minimax, security values, and linear-program duality.
- `game-theory:002000` - **Mutual Best Responses**: pure and mixed Nash equilibrium, existence, and correlated coordination.
- `game-theory:003000` - **Credible Threats**: sequential subgames, backward induction, and an explicit repeated-game discount threshold.
- `game-theory:004000` - **Strategies When Information Is Private**: types, Bayes updates, and a fully checked first-price bidding equilibrium.
- `game-theory:005000` - **Rules That Make Truthful Play Rational**: second-price dominance, VCG payments, and the revelation principle.

Each lecture includes one spoken segment and a non-spoken mathematical companion with exact notation, worked calculations, exercises, solutions, and reading links. `track.json` owns lecture order and `navigation.json` offers focused paths.
